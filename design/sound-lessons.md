One dated bullet per lesson. Promote to `sound-style-guide.md` when it becomes a rule.

- 2026-10-18 (smoke test, test_click): The pitch-drop sine + short low-passed noise tick recipe produced a clean pop on the first try. Second iteration only shortened the tail so the fade-out no longer cut audible ringing.
- 2026-10-18: Normalising RMS over "audible = above -40 dB relative to peak" in the generator lands within about ±1 dB of sound-check's measurement (absolute -40 dBFS threshold, after Vorbis). Good enough; no need to replicate sound-check exactly.
- 2026-10-18: Vorbis decoding leaves a small non-zero first sample even after a 1 ms fade-in, and moves peaks by a few tenths of a dB (seen up to ±1 dB on grainy sounds). Keep the generator's peak ceiling at -2 dBFS.
- 2026-10-18: A spectrogram with a -120 dB floor makes faint codec noise look like content; the preview renderer uses -100 dB.
- 2026-10-18: Paper 26.3 `SoundCategory` has a `UI` constant, so UI sounds use `source: ui` in sounds.yml.
- 2026-10-18 (bakery-core): Crunch grains normalised by peak made single grains set the file's peak, so the peak ceiling, not the RMS target, decided the level (RMS -19 to -20). Soft-clipping the summed crumb layer with tanh (drive 2.2) fixed it in one step. Promoted to the style guide.
- 2026-10-18 (bakery-core): A 2nd-order 7-8 kHz final low-pass still left faint 10-15 kHz fizz from the noise grains on the spectrogram; 4th order removed it without dulling the crunch. Promoted.
- 2026-10-18 (bakery-core): First cant_afford draft sat at 150-260 Hz: fine on headphones, near-silent on laptop speakers, and peak -8.6 dBFS at -19 RMS (sounds quieter than its RMS). Pitched it up to 175-340 Hz with a 140 Hz buzz low-passed at 1.1 kHz so its harmonics carry. Keep error fundamentals above ~170 Hz. Promoted.
- 2026-10-18 (bakery-core): A 2 ms attack on the second thud of a double-thud made a visible broadband click on the spectrogram; 4 ms removed it.
- 2026-10-18 (bakery-core): Bell partials ≥ 4× on a C7 note (8.7 kHz) looked harsh on the spectrogram; high sparkle notes now use only partials 1, 2, 3.
- 2026-10-18: `sf.write(..., compression_level=...)` does apply to Vorbis in soundfile 0.14.0 (0.0 = highest quality, largest file; 1.0 = smallest). The default is fine for short UI sounds; not used.
- 2026-10-18 (bakery-core): 3 generate/measure/preview iterations for 4 events (7 files). All passed sound-check from the first run; iterations were for crest factor, high-frequency fizz and small-speaker audibility.
- 2026-10-18 (bakery-core): libsndfile writes a random Ogg stream serial on every encode, so "fixed seeds" alone still gave different .ogg bytes each run (git churn on every `mise run sounds`). Only the serial and page CRCs differed; `synth.write()` now sets a fixed serial and recomputes the CRCs, and regeneration is byte-identical.
- 2026-10-19 (starter-house): Long sounds (fanfare, crackle) were peak-limited on the first pass (-19.8 / -23.1 LUFS): stacked pluck attacks and impulsive crackles set the peak. A gentle whole-mix tanh `synth.soft_limit` (drive 1.6-2.0) reached the LUFS target without visible distortion. Promoted.
- 2026-10-19 (starter-house): Soft-limiting *after* the final low-pass put saturation harmonics up to 18 kHz on the spectrogram; limit first, then filter.
- 2026-10-19 (starter-house): Raising a noise bed to gain loudness made the fire read as "rain/hiss" on the spectrogram (haze up to 7 kHz); a 450 Hz, 3rd-order bed gives rumble, and the crackles alone carry the highs.
- 2026-10-19 (starter-house): Seamless loops: build the whole buffer circularly (wrap events with `place_circular`, filter with the FFT-domain `fft_filter`, periodic noise from an FFT of exactly N samples) and dip the bed near the loop point. Result: end-to-start jump -55 dBFS, smaller than a normal sample step, and sound-check's leading-silence/abrupt-end rules both pass without fades.
- 2026-10-19 (starter-house): The nail "tink" of the hammer looked like a steady 100 ms tone on the spectrogram with 30 ms partial decays; 9-20 ms decays read as a tick, not a beep.
- 2026-10-19 (starter-house): When the vanilla fallback shares sounds.yml's pitch (SoundService has one pitch range for both), author the custom file for the pitch the fallback needs (hammer authored at 1/1.25 so it sits right at pitch 1.15-1.35).
- 2026-10-19 (starter-house): 6 generate/measure/preview iterations for 4 events (10 files): all passed sound-check from the first run; iterations were for loudness (fanfare, crackle x3), nail-ping length and thunk boominess.
- 2026-10-20 (factory-makeover): A tonal loop (hum) has no natural quiet spot, so sound-check's seam rules bind from both sides: last 2 ms < -30 dBFS and first 5 ms > -40 dBFS. A 55 % loop-point dip ended at -23.8 dBFS (fail), 95 % gave 9 ms leading silence (fail), 85 % (Gaussian, 80 ms wide) passed. Aim the dip level for about -33 dBFS at the seam.
- 2026-10-20 (factory-makeover): Seamless tonal loops: every partial must have a whole number of cycles in the loop (frequencies multiples of 1/length Hz, e.g. 0.25 Hz for 4 s); a detuned second voice at +1/length Hz gives one slow swell per loop for free. Put the rhythm's bar line on the loop point so the seam dip reads as part of the groove. Fixed pitch for tonal loops (no pitch spread), so overlapping replays can't phase. 3 generator runs, 2 of them real sound-check failures.
- 2026-10-21 (conveyor-belt): SoundService shares one pitch between our key and the vanilla fallback, and the belt fallback (`block.beehive.work`) needs a low pitch. A tonal loop can't take a pitch spread, so it was authored for a fixed 0.8: designed at the in-game length (5.0 s, partials multiples of 0.2 Hz), then `scipy.signal.resample` (FFT, circular) to the 4.0 s file. The loop stays seamless (end-to-start jump -63 dBFS) and at 0.8 it lasts a whole number of ticks (100). Pick the play pitch so length/pitch is a whole number of ticks.
- 2026-10-21 (conveyor-belt): A -20.0 LUFS generator target landed at -20.1 after Vorbis and triggered sound-check's loudness warning (range -16 ±4); aim for -19.8 when a bed must sit at the bottom of the range, and make it quieter with the config volume instead.
- 2026-10-21 (conveyor-belt): Rhythmic loops: put the events on the half-grid (offset = half the event period) so none falls near the loop point, and apply the Gaussian loop dip after the final circular filter; seam came out end -33.5 dBFS / start -28.6 dBFS on the first try. 3 generator runs (loudness warning, then the pitch-0.8 rework), 0 sound-check failures.
- 2026-10-21 (upgrade-holograms): Short UI ticks (90 ms) and a 300 ms clink (tok + two low-passed bells) hit -17.7..-18.1 dBFS RMS on the first run using the purchase/click recipes unchanged; no tuning needed. 1 iteration, 0 failures.
- 2026-10-22 (plot-polish): audited the three ambient loops: exact lengths (4.0/3.0/4.0 s), wrap jump < 0.002, head/tail ~-35 dB (soft dip), so files are fine. A loop's pitch must be fixed: random pitch on the crackle made it 2.91-3.09 s against a fixed 60-tick period (gaps/doubles). Always write the replay period in the sounds.yml comment.
